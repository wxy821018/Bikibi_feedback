## English

**Bikibi** is a fitness coach matching platform that connects athletes with professional personal trainers for 1-on-1 sessions — at home, at the gym, or outdoors.

🌐 **App**: [bikibi.com](https://bikibi.com)

### How to Submit Feedback

This repository is the **public issue tracker** for the Bikibi app. You can report bugs, request features, or share any ideas here.

> ⚠️ This repo contains **no source code**. It exists only for community feedback.

#### 🐛 Report a Bug
1. Click **[Issues](../../issues)** → **New Issue**
2. Choose the **Bug Report** template
3. Fill in the steps to reproduce, your device, and screenshots if possible

#### 💡 Request a Feature
1. Click **[Issues](../../issues)** → **New Issue**
2. Choose the **Feature Request** template
3. Describe your use case and what you'd like to see

#### 👍 Vote on Existing Issues
Browse open issues and **react with 👍** to upvote ones you care about. We prioritize based on community votes.

### Labels

| Label | Description |
|-------|-------------|
| `bug` | Something isn't working correctly |
| `feature-request` | New functionality or improvement |
| `ui/ux` | Visual or interaction design feedback |
| `payment` | Booking, payment, or billing issues |
| `coach` | Coach-side app features |
| `user` | User/athlete-side app features |
| `android` | Android-specific issue |
| `ios` | iOS-specific issue |
| `web` | Web (bikibi.com) specific issue |
| `in-progress` | We're actively working on this |
| `planned` | Confirmed for a future release |
| `wontfix` | Out of scope or intentional behavior |

## 中文

**Bikibi** 是一个健身教练匹配平台，帮助用户找到专业私人教练进行一对一训练，支持上门、健身房、户外等多种场景。

🌐 **应用地址**：[bikibi.com](https://bikibi.com)

### 如何提交反馈

本仓库是 Bikibi 应用的**公开问题追踪系统**。你可以在这里报告 Bug、提出功能建议或分享任何想法。

> ⚠️ 本仓库**不包含任何源代码**，仅用于社区反馈收集。

#### 🐛 报告 Bug
1. 点击 **[Issues](../../issues)** → **New Issue**
2. 选择 **Bug Report** 模板
3. 填写复现步骤、你的设备信息，如有截图请一并上传

#### 💡 功能建议
1. 点击 **[Issues](../../issues)** → **New Issue**
2. 选择 **Feature Request** 模板
3. 描述你的使用场景和期望功能

#### 👍 为已有建议投票
浏览已有的 issue，对你关心的内容**点击 👍 反应**，我们会优先处理票数高的问题。

### 提交语言
中文、英文均可，欢迎直接用你习惯的语言描述。
